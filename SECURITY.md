# Security Policy

## Supported versions

This project currently supports the latest `main` branch.

## Reporting a vulnerability

If you find a security issue, please do not open a public issue first.

Instead, report it privately by contacting the repository owner directly through GitHub.
Include:

- A clear description of the issue
- Reproduction steps
- Potential impact
- Suggested mitigation (if known)

We will acknowledge reports as quickly as possible and provide updates on remediation.
